    Live ↗

    A booking and payments platform I built and ran end to end alone, as founding engineer.

  2. 02Owuwe

    Live ↗

    A multi tenant commerce operations platform: CRM, orders, delivery, inventory, remittance and marketing in one place.

    The infrastructure is code, and the dev stack costs almost nothing when idle.

    AWS CDK in TypeScript defines a VPC with no NAT gateway or load balancer, Postgres 16 on RDS in an isolated subnet, an ARM64 Fargate API that starts at zero tasks, and SQS queues with dead letter queues for assignment timeouts, escalations, webhook intake and notifications. Budgets and anomaly detection alert on spend.

    • AWS CDK
    • ECS Fargate
    • RDS Postgres
    • SQS
    • Multi tenant SaaS
